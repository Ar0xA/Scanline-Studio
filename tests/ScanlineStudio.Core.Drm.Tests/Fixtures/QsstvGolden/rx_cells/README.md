# QSSTV RX channel-estimation golden (P5c)

QSSTV `demodulator::channelEstimation` (`demodulator.cpp:524-1132`) output, one row per equalized frame.

- Generated by `~/tools/qsstv-drm-harness/make_rx_cells.py` (run after `make_fixtures.py` and
  `make_rx_acq.py`). The harness `rx` command with `HARNESS_RX_CELLS=1` reads the private demodulator
  members and the drm.cpp globals read-only after each stripe in which a frame was equalized
  (`symbol_counter` moved to a non-zero value). Input: the case's QSSTV TX stream regenerated by the harness
  (sha256 equal to the fixture's `out48k` sha256), 4096-sample blocks, `--tail-zero-blocks 8`, as `../<case>/rx/`.
  Every case's `rx_sync`, `rx_frames`, `rx_msc_bits` (hook off and on) and `../rx_acq/<case>/rx_acq.csv`
  (hook on) were byte-identical to the committed fixtures.
- Floats are printed with 9 significant digits (exact float32 round trip); the energies with 17 (double).

| file | content |
|---|---|
| `<case>/rx_cells.csv.gz` | per frame: stripe, `transmission_frame_buffer_wptr` before the stripe, `symbol_counter`, `rsbufwidx`, `symbufwidx`, `input_samples_buffer_request`, `iterationCounter`, `Zi0..Zi5`, `delta_freq_offset`, `freqOffset`, `deltaFS`, `samplerate_offset`, `WMERFAC`, `mean_energy_of_used_cells`, `lFAC`, `mode_and_occupancy_code(_last)`, `SNR_timeout_counter`, `SNR_time_out_counter` (the init-only twin, demodulator.cpp:50), `fac_not_valid_counter`, `doSynchronize`, `transmission_frame_buffer_data_valid`, the three `smp_rate_conv_*`, `K_min`, `K_max`, `spectrum_occupancy` (after channel_decoding), and the double sums of \|cell\|^2 and \|H\|^2 over the frame's K_min..K_max cells |
| `<case>/fac_cells.f32.gz` | per frame: `FAC_cells_sequence` (lFAC complex, float32 re, im) |
| `<case>/cells.f32.gz`, `<case>/h.f32.gz` | FULL cases only (A0_q4_high_long, B1_q16_high_long, E1_q4_high_long): per frame the equalized cells (`transmission_frame_buffer`) and the channel estimate (`channel_transfer_function_buffer`), `symbols_per_frame` x (K_max-K_min+1) complex, float32 |
| `<case>/w.f32.gz`, `<case>/w.json` | one case per mode x SO: the first frame's Wiener tables from QSSTV's Numerical Recipes LU (`ludcmp`/`lubksb`): per `nnn`, `cnt_tr_cells` rows of `W_symbol_blk` (K_max-K_min+1 each), then `cnt_tr_cells` rows of `W_pilots_blk` (`cnt_next_pilot_cells` each); `w.json` holds the integer pilot tables and the sha256 of the uncompressed W data |
| `summary.json` | per case: frames, and which optional files exist |
