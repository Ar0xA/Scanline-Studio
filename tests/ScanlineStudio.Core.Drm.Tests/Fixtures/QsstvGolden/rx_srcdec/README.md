# QSSTV RX source-decoder golden on packet sequences (P7a)

QSSTV `sourceDecoder::decode()` (`sourcedecoder.cpp:72-708`, with `reedSolomonCoder::decode`, `rs.cpp`
`eras_dec_rs`) on MSC packet sequences a clean OTA run never produces, so reassembly, continuity, the save rules,
RS erasure decode and naming are pinned where they matter.

- Generated by `~/tools/qsstv-drm-harness/make_rx_srcdec.py` (run after `make_fixtures.py`) with the harness
  `srcdec` command (`harness/srcdec.cpp`). Per frame it sets `channel_decoded_data_buffer` (the packet bits, MSB
  first, then zero bits up to `bits`), `length_decoded_data`, `channel_decoded_data_buffer_data_valid`,
  `audio_data_flag`, optionally `callsignValid`/`drmCallsign`, and the FAC globals a new transport block reads, then
  calls `srcDecoder->decode()` (`"init": true` calls `srcDecoder->init()` instead). No QSSTV file is touched.
- Inputs: either the committed `msc_packets` of a TX case with whole MOT segments removed (`*_missing_*`) or packets
  altered (`corrupt_mix`, `header_after_body`), or MOT objects built by the script (`names`, `rs_crafted`,
  `interleaved`, `ppi_wrap`, `eviction`). Before building, the script checks that its MOT data-group, MOT header,
  packet and RS encoders reproduce the committed TX goldens byte for byte. After generation it regenerated all
  79 cases' TX streams and RX runs with the same binary: `rx_sync`, `rx_frames`, `rx_msc_bits` and `rx_manifest.json`
  were byte-identical to the committed fixtures.
- The RX folder is `<out>/rx/saved`; files are listed below `<out>/rx`, named relative to the RX folder, so a name
  with "../" that leaves it is still seen. Event text has the RX folder replaced by `<rx>`.

| file | content |
|---|---|
| `<scenario>/srcdec.json.gz` | FAC globals and per frame `valid`, `audio`, `bits`, `hex` (packet bytes), optional `callsign`/`init` |
| `<scenario>/srcdec.csv.gz` | per frame after decode: `msc_valid`, the data group as rx_frames prints it (CRC-valid last packet only), `currentSegmentNumber`, `rxTransportID`, `bodyTotalSegments`, `rxSegments`, `callsignValid`, `drmBlockList.count()` |
| `<scenario>/srcdec_manifest.json` | transport blocks, files written (name, bytes, sha256), events, bsr payloads |
| `<scenario>/bsr_received_<i>.bin` | `prepareFixEvent` payloads |
