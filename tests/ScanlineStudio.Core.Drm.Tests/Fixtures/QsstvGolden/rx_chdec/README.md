# QSSTV RX channel-decoding golden on noisy frames (P6)

QSSTV `channel_decoding()` (`channeldecode.cpp:79-887`, with `msdhardfac`, `msdhardmsc`, `viterbi_decode`,
`mkmscmap`, `deinterleaver`, `crc8_c`) on synthetic equalized frames, so the bit metrics, Viterbi decisions,
refinement passes and FAC path are pinned where the decoder makes errors, without the FFT-dependent demodulator.

- Generated by `~/tools/qsstv-drm-harness/make_rx_chdec.py` (run after `make_fixtures.py`) with the harness
  `chdec` command (`harness/chdec.cpp`): it sets the globals channelEstimation leaves (`robustness_mode`,
  `symbols_per_frame`, `K_dc`, `K_modulo`, `spectrum_occupancy` from `so_est` when ≤ 0, `fac_valid` = 1 on a
  data-valid frame), writes each frame's cells and H at `transmission_frame_buffer_wptr + s·K_modulo + K_dc + k`
  for K_min..K_max, and calls `channel_decoding()`. No QSSTV file is touched. After generation the script
  regenerated all 79 cases' TX streams and RX runs with the same binary: `rx_sync`, `rx_frames` and `rx_msc_bits`
  were byte-identical to the committed fixtures.
- Inputs: the clean cells are the case's committed `cell_grid` from TX frame `first_tx_frame` on; per frame
  complex Gaussian noise of the listed sigma (three configs sit at the FAC decoder's threshold) divided by |H| (numpy `default_rng(seed)`), and a synthetic complex
  H (smooth fading magnitude 0.15..1, random phase), all float32. Frames listed in `invalid` are sent with
  `transmission_frame_buffer_data_valid = 0`.

| file | content |
|---|---|
| `<config>/config.json` | case, mode, `so_est`, first TX frame, per frame sigma and data_valid |
| `<config>/frames.f32.gz` | per frame `symbols_per_frame x (K_max-K_min+1)` complex cells, then the same count of complex H (float32 re, im) |
| `<config>/chdec.csv.gz` | per frame after channel_decoding: write pointer before/after, `fac_valid`, `spectrum_occupancy`, the FAC fields, `callsignValid`/`drmCallsign`, `lFAC`, `lMSC`, `channel_decoded_data_buffer_data_valid`, `length_decoded_data`, sha256 of `MSC_Demapper[6][lMSC]` (int32 LE) and of the whole `transmission_frame_buffer` (float32) |
| `<config>/chdec_bits.bin.gz` | `bit_u8`: the decoded bits of every frame with data_valid ≠ 0 (1 and 2), `length_decoded_data` each |
