# QSSTV RX acquisition golden (P5b)

QSSTV demodulator acquisition state (`demodulator.cpp:116-520`), read after every `drmRx::run` stripe.

- Generated by `~/tools/qsstv-drm-harness/make_rx_acq.py` (run after `make_fixtures.py`). The harness `rx`
  command with `HARNESS_RX_ACQ=1` reads the private demodulator members read-only after each stripe. Input:
  the case's QSSTV TX stream regenerated by the harness (sha256 equal to the fixture's `out48k` sha256),
  4096-sample blocks, `--tail-zero-blocks 8`, exactly as `../<case>/rx/`. Every case's `rx_sync`,
  `rx_frames` and `rx_msc_bits` were byte-identical to the committed fixture with the hook off and on.
- Values are float32 printed with 9 significant digits (exact round trip).

| file | content |
|---|---|
| `<case>/rx_acq.csv.gz` | per stripe: `iterationCounter`, `counter` (time-sync count), `rsbufwidx`, `symbufwidx`, `symbol_counter`, `input_samples_buffer_request`, `time_offset`, `time_offset_integer`, `samplerate_offset_estimation`, `frequency_offset_fractional_init`, `freq_offset_integer`, `freq_offset_init`, `time_offset_fractional_init`, `delta_time_offset_I_init`, `Zi0..Zi5` |
| `<case>/handoff.f32.gz` | full-stream cases only: the first frame-sync handoff (`frameSync` done, `channelEstimation` not yet run, `symbol_counter==0`): `symbol_buffer` (`symbols_per_2D_window` x `K_modulo` complex), then the aligned `rs_buffer` residual (`rsbufwidx` complex), float32 (re, im) pairs |
| `<case>/handoff.json` | the handoff stripe, sizes, and the sha256 of the uncompressed handoff data |

`rsbufwidx`, `symbufwidx`, `symbol_counter`, `input_samples_buffer_request` and `Zi` also change in
`channelEstimation` (P5c); the acquisition fields (`time_offset` .. `delta_time_offset_I_init`) are written
only by `timeSync`/`frequencySync`.
