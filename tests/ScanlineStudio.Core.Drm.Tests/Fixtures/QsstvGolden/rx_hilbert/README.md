# QSSTV RX Hilbert golden (P5a)

QSSTV's 153-tap real-to-complex filter as `drmRx::run` applies it (`drmrx.cpp:64`,
`filters.cpp:133-162`, `filter.cpp:292-312`, `filterparam.h:68-69`, `filterparam.cpp:501-507`).

- Generated by `~/tools/qsstv-drm-harness/make_rx_hilbert.py` (run after `make_fixtures.py`). The
  harness `rx` command with `HARNESS_RX_HILBERT=1` feeds a second, unmodified `drmHilbertFilter` the same
  12 kHz stripes `drmRx::run` receives. drmRx's own `iqFilter` has no other caller, so the outputs are equal.
- Input: the case's `out48k.bin.gz`, 4096-sample blocks, `--tail-zero-blocks 8`, exactly as `../<case>/rx/`.
  The harness re-checks that its `rx_stripes_12k` sha256 equals the committed one.
- Precision: the filter accumulates in double (`FILTERPARAMTYPE`) and stores float32 (`resamp_signal`,
  `drmrx.h:26`). Output per sample is a float32 pair: `[2k]` = `resQ/gain` (the Hilbert part),
  `[2k+1]` = the input delayed by 76 samples.

| file | content |
|---|---|
| `<case>/hilbert_re.f32.gz` | `[2k]` for the full stream (all stripes), float32 LE |
| `<case>/hilbert_head.f32.gz` | the full interleaved pairs for the first 8 stripes, float32 LE |
| `<case>/manifest.json` | stripe count, the sha256 of the full uncompressed interleaved stream and of each file |

The full-stream `[2k+1]` half is not stored: it is float32 of the committed `rx_stripes_12k` delayed by
76, which the tests check over the full stream; `hilbert_head` pins it against QSSTV output directly.
